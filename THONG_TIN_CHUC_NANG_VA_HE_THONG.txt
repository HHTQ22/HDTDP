   - Quy tắc: MỖI LẦN SỬA ĐỔI (sửa lỗi, tinh chỉnh thuật toán, tối ưu giao diện,
     thêm tiện ích nhỏ, dọn dẹp file...) khi hoàn thành sẽ được tính là 1 BẢN CẬP NHẬT NHỎ.
   - Đánh số: Tăng chỉ số phụ ở cuối (ví dụ: từ v2.18 lên v2.18.1, v2.18.2...).

2. BẢN CẬP NHẬT LỚN (Major Release Update - dạng v2.12 ➔ v2.13 ➔ ... ➔ v2.18 ➔ v2.19):
   - Quy tắc: Khi hoàn thành một tính năng/phân hệ hoàn chỉnh HOẶC KHI CÓ LỆNH TẠO CẬP NHẬT
     từ Quản trị viên (đóng gói toàn bộ và phát hành lên GitHub) sẽ được tính là 1 BẢN CẬP NHẬT LỚN.
   - Đánh số: Tăng số phiên bản chính (ví dụ: v2.18 ➔ v2.19, v2.20...).
      + PC_CPP\\AutoUpdater.h (hằng số APP_VERSION).
     `MOBILE/index.html` (`CURRENT_VERSION`), đóng gói qua `DONG_GOI_TAT_CA.bat` và đẩy lên
     GitHub (`DAY_LEN_GITHUB.bat`) để kích hoạt Auto-Updater cho toàn bộ máy khách.

I. TỔNG QUAN NGHIỆP VỤ & CÁC PHÂN HỆ CHỨC NĂNG CHI TIẾT
================================================================================

1. MỤC ĐÍCH CỐT LÕI CỦA HỆ THỐNG:
   Tự động hóa 100% quy trình đối chiếu doanh thu bán lẻ từ KiotViet (hoặc file POS/Sổ quỹ)
   với danh mục tồn kho kế toán MISA, tự động bốc tách hàng hóa hợp lệ và phân bổ doanh thu
   để xuất hóa đơn điện tử chuẩn 17 cột cơ quan Thuế mà không làm âm kho hay lệch tiền thuế.

2. PHÂN HỆ 1: XỬ LÝ HÓA ĐƠN & PHÂN BỔ TỒN KHO (TAB CHÍNH - PC & MOBILE)
   a) Dữ liệu đầu vào (Input):
      - File Hóa đơn KiotViet (.xlsx, .xls, .csv):
        + Thuật toán chấm điểm dòng tiêu đề (`find_best_header_idx`) tự động bỏ qua các dòng
          tên báo cáo hoặc dòng giao dịch để tìm đúng dòng tiêu đề cột.
        + Tự động nhận diện cột tiền thanh toán ('Giá trị', 'Tổng tiền', 'Khách đã trả', 'Thành tiền').
        + Trên Mobile hỗ trợ thêm hộp chọn cột tính tiền linh hoạt nếu file có cấu trúc đặc thù.
      - File Tồn kho MISA (.xlsx, .xls):
        + Tự động nhận diện cột Mã hàng, Tên hàng, Đơn vị tính (mặc định 'Cái'), Số lượng tồn
          ('Tồn cuối', 'Khả dụng', 'Số lượng tồn', 'Tồn kho') và cột Thuế suất VAT (mặc định 8%).
        + Chỉ lấy đơn giá từ cột 'Đơn giá bán 1' (hoặc 'Giá bán 1', 'Đơn giá bán', 'Giá niêm yết'),
          TUYỆT ĐỐI không lấy giá vốn/giá mua.
        + Tự động bỏ qua các mặt hàng trống giá, giá <= 0 hoặc tồn kho <= 0.
        + Tự động gộp cộng dồn tồn kho nếu file MISA có các mã hàng trùng lặp ở nhiều kho.

   b) Chế độ xuất & Gom hóa đơn linh hoạt:
      - Chế độ 1 (Mặc định): Xuất theo từng hóa đơn bán lẻ KiotViet (1 HĐ Kiot ➔ 1 HĐ Thuế).
      - Chế độ 2 (Gom 1 HĐ): Gộp toàn bộ doanh thu KiotViet thành 1 hóa đơn tổng duy nhất
        (tự động gợi ý tăng số dòng tối đa/HĐ lên 20 dòng để bốc đa dạng mặt hàng).
      - Chế độ 3 (Gom N HĐ): Chia tổng doanh thu KiotViet thành số lượng hóa đơn tùy chọn
        (VD: 2, 3, 5, 10, 20 HĐ) với thuật toán `chia_tien` dao động tự nhiên 60% - 140% quanh
        mức trung bình nhưng tổng vẫn khớp tuyệt đối 100%.
      - Tùy chỉnh: Số dòng tối đa/HĐ, Hình thức thanh toán (Chuyển khoản / Tiền mặt), Ngày hóa đơn.

   c) Thuật toán bốc tách hàng tồn kho & Cân bằng thuế tuyệt đối (Sai số = 0 VNĐ):
      - Lấy mẫu ngẫu nhiên có trọng số (Weighted Random Sampling) với trọng số `stock ^ 1.25`:
        + Ưu tiên giải phóng mặt hàng tồn kho dồi dào (Tồn > 20: bốc 2-8 cái/lần).
        + Nhóm tồn trung bình (Tồn 6-20: bốc 2-5 cái/lần).
        + Chế độ bảo vệ kho cho hàng tồn ít (Tồn <= 5: chỉ bốc 1-2 cái khi thật sự cần).
      - Thuật toán cân bằng Diophantine 2 biến (`solve_two_items_robust` - 3 tầng Pass 1/2/3):
        + Dành 2 mặt hàng cuối cùng trong hóa đơn để giải phương trình cân bằng nguyên.
        + Pass 1 & 2: Quét tổ hợp số lượng và đơn giá trong biên độ bám sát giá bán MISA (±5%, ±12%, ±20%).
        + Pass 3: Vi chỉnh một vài đồng trên đơn giá để `[Thành tiền + Tiền thuế GTGT]` khớp
          từng đồng (sai số = 0 VNĐ) với tổng tiền hóa đơn KiotViet.
      - Cơ chế xử lý thiếu kho thông minh: Nếu giữa chừng hết tồn kho không tạo đủ số HĐ,
        hệ thống hiển thị hộp thoại cho phép: [Yes] Thử phân bổ lại tổ hợp ngẫu nhiên khác,
        [No] Vẫn lưu số HĐ đã tạo được, hoặc [Cancel] Hủy để kiểm tra lại kho.

   d) Dữ liệu đầu ra chuẩn xác (2 File Excel hoàn chỉnh):
      - File 1: `HOADON_ddmmyyyy.xlsx`
        + Sheet `HOADON`: Đúng chuẩn 17 cột Hóa đơn điện tử cơ quan Thuế (STT HĐ, Ngày, Tên đơn vị,
          Địa chỉ, MST, Người mua hàng 'Người tiêu dùng', Email, Hình thức, Mã hàng, Tên hàng,
          ĐVT, Số lượng, Đơn giá, Thành tiền, Thuế suất, Tiền thuế GTGT, Tổng tiền thanh toán sau VAT).
        + Sheet `TONKHO`: Bảng đối chiếu (Mã hàng, Tên hàng, Tồn cũ, Đã xuất, Tồn mới) và tự động
          tô màu hồng nhạt (`#FFC7CE`) các mặt hàng có phát sinh xuất kho.
        + Tự động kẻ khung viền, tô màu tiêu đề xanh đậm (`#1F497D`) và căn chỉnh độ rộng cột (Auto-fit).
      - File 2: `MISA_DaTruTonKho_ddmmyyyy.xlsx`
        + Giữ nguyên 100% cấu trúc file MISA gốc, tự động trừ trực tiếp số lượng đã xuất vào đúng
          cột tồn kho và bôi màu đánh dấu các dòng đã trừ để kế toán import ngược vào MISA.

3. PHÂN HỆ 2: TAB LỌC & LÀM SẠCH TỒN KHO MISA (PC & MOBILE)
   - Hỗ trợ chọn 1 hoặc nhiều file tồn kho MISA (.xlsx, .xls, .csv) hoặc kéo thả trực tiếp.
   - Tự động loại bỏ các file rỗng (0 byte), file lỗi hoặc không có cấu trúc tồn kho MISA.
   - Tự động nhận diện và cho phép ánh xạ thủ công 6 cột chuẩn: Mã hàng, Tên hàng, Số lượng tồn,
     Đơn giá bán 1, ĐVT, Thuế VAT mặc định.
   - Tự động xóa bỏ triệt để 4 nhóm dòng lỗi không hợp lệ trong file MISA:
     1) Xóa dòng trống: Thiếu Mã hàng, thiếu Tên hàng, hoặc các dòng Tổng cộng / Cộng nhóm cuối bảng.
     2) Xóa dòng không có tồn: Số lượng tồn trống hoặc bằng 0 (`= 0`).
     3) Xóa dòng tồn bị âm: Số lượng tồn `< 0` (hỗ trợ cả định dạng `-5` và định dạng kế toán `(5)`).
     4) Xóa dòng không có giá bán: Cột Đơn giá bán 1 bị trống hoặc `<= 0`.
   - Tùy chọn tự động gộp các mã hàng trùng lặp (cộng dồn số lượng tồn hợp lệ).
   - 6 thẻ KPI thống kê trực quan: Tổng dòng file MISA, Hợp lệ giữ lại, Xóa trống Mã/Tên,
     Xóa không tồn (=0), Xóa tồn âm (<0), Xóa không giá bán.
   - Bộ lọc chế độ xem đối chiếu (Xem hàng hợp lệ giữ lại / Xem từng nhóm dòng lỗi đã xóa kèm lý do)
     và ô tìm kiếm nhanh theo Mã/Tên hàng thời gian thực; cho phép chọn dòng xóa thủ công bằng phím Delete.
   - Nút 1-Click `💾 Xuất File MISA Đã Lọc (.xlsx)`: Xuất file sạch chuẩn cấu trúc MISA (không chèn dòng
     tổng cộng cuối bảng để có thể nạp lại MISA ngay).
   - Nút 1-Click `🚀 DÙNG FILE MISA ĐÃ LỌC TẠO HÓA ĐƠN`: Tự động lưu file sạch và nạp thẳng vào ô
     File Tồn Kho MISA ở Tab chính.

4. PHÂN HỆ 3: TAB GOM & SẮP XẾP NHIỀU FILE HÓA ĐƠN (PC & MOBILE)
   - Giải quyết bài toán doanh nghiệp có nhiều file hóa đơn/sổ quỹ/phiếu thu nhỏ lẻ từ nhiều ca,
     nhiều máy thu ngân hoặc nhiều ngày.
   - Chọn nhiều file cùng lúc (.xlsx, .xls, .csv), chọn cả thư mục (quét đệ quy), hoặc kéo thả hàng loạt.
   - Tự động bóc tách 9 trường thông tin: Mã phiếu/HĐ, Thời gian, Loại thu chi (tự động phân biệt
     Phiếu thu / Phiếu chi), Phương thức, Tên tài khoản, Số tài khoản, Người nộp/nhận, Giá trị, File nguồn.
   - Tự động lọc sạch các dòng tóm tắt chân trang không phải giao dịch: Quỹ đầu kỳ, Tổng thu,
     Tổng chi, Tồn quỹ, Số dư, Tổng cộng.
   - Chuẩn hóa thời gian (hỗ trợ cả ISO, DD/MM/YYYY, Excel Serial Date) và sắp xếp chuẩn xác:
     + Tăng dần (Cũ ➔ Mới: Sáng đến Tối) hoặc Giảm dần (Mới ➔ Cũ: Tối đến Sáng).
   - Tùy chọn Lọc trùng mã phiếu (Deduplicate).
   - 4 thẻ KPI thống kê: Số file đã gom, Tổng số phiếu, Tổng tiền giao dịch, Khoảng thời gian (Từ giờ ➔ Đến giờ).
   - Xuất file Excel tổng (`GOM_HOADON_TONG_...xlsx`) có công thức `=SUM(...)` ở dòng TỔNG CỘNG cuối bảng.
   - Nút 1-Click `🚀 Dùng File Này Để Tạo HĐ Thuế`: Chuyển thẳng danh sách đã gom sang đầu vào KiotViet.

5. PHÂN HỆ 4: KÉO THẢ FILE TRỰC TIẾP THÔNG MINH (DRAG & DROP - PC & MOBILE)
   - Trên PC sử dụng `tkinterdnd2`, trên Web/Mobile sử dụng HTML5 Drag & Drop API.
   - Kéo thả riêng từng file vào ô KiotViet, ô MISA, bảng Xem trước Kiot, hoặc bảng Xem trước MISA.
   - Kéo thả thông minh 2 file cùng lúc vào khung cấu hình: Tự động nhận diện tên file chứa từ khóa
     (`misa`, `ton`, `kho`, `vthh`) để phân bổ 1 file vào MISA và 1 file vào KiotViet.
   - Kéo thả nhiều file vào Tab Lọc Kho MISA hoặc Tab Gom File Hóa Đơn để xử lý hàng loạt.

6. PHÂN HỆ 5: BẢN QUYỀN THIẾT BỊ (DRM), CỬA SỔ CHÀO MỪNG & KEYGEN ADMIN
   - Định danh thiết bị (Machine ID):
     + Bản PC: Băm MD5 địa chỉ phần cứng MAC (`uuid.getnode()`) lấy 8 ký tự Hex in hoa (VD: `A1B2C3D4`),
       lưu license tại `~\PM_HoaDon_License.dat`.
     + Bản Mobile: Sinh mã thiết bị 8 ký tự lưu bền vững trong `localStorage`.
   - Cấu trúc khóa bản quyền (18 ký tự: `HH` + `8 ký tự Hex Timestamp hết hạn` + `8 ký tự chữ ký HMAC-SHA256`
     với khóa bí mật `BiaLoiHoaDon2026!@#`).
   - Cửa sổ Chào mừng & Lưu ý trách nhiệm (Welcome Modal):
     + Hiển thị ngày làm việc, thời hạn bản quyền, 4 thông báo kiểm tra công việc và 5 lưu ý
       trách nhiệm pháp lý/kế toán trước khi vào giao diện chính.
   - Công cụ KeyGen Admin:
     + Trên PC: Ứng dụng độc lập `KeyGen.exe` (`PC/keygen.py`).
     + Trên Mobile ("Tập trung 1 mối"): Mở bằng cử chỉ bí mật (nhấn giữ 1.5 giây hoặc chạm nhanh 5 lần
       vào biểu tượng ⚡ hoặc tiêu đề 🔒) + xác thực mã PIN Admin (mặc định `6868`, hỗ trợ đổi PIN,
       khóa phiên Admin, chọn hạn 30/90/180/365 ngày hoặc tùy chỉnh, lưu lịch sử 10 mã gần nhất,
       sao chép & gửi trực tiếp qua Zalo).

7. PHÂN HỆ 6: TỰ ĐỘNG CẬP NHẬT (AUTO-UPDATER) & ĐÓNG GÓI PHÁT HÀNH GITHUB
   - Auto-Updater trên PC (`PC/updater.py`):
     + Tự động kiểm tra ngầm sau 2.5 giây khi khởi động ứng dụng hoặc bấm nút `🔄 Cập nhật (vX.YY.Z)`.
     + Đối chiếu phiên bản với `https://raw.githubusercontent.com/HHTQ22/HDTDP/main/version.json`.
     + Tải gói `PM_HoaDon.zip` từ GitHub Releases với thanh tiến trình phần trăm/MB, tự động giải nén,
       chạy script ngầm thay thế file thực thi, dọn dẹp các file `.txt`/`icone.ico` thừa ở thư mục gốc
       máy khách và khởi động lại phiên bản mới.
   - Đồng bộ cập nhật trên Mobile:
     + Kiểm tra `version.json` và hiển thị Banner thông báo phiên bản mới kèm Changelog.
     + Bản APK Android (TWA/PWA) tự động đồng bộ giao diện mới từ GitHub Pages (`https://hhtq22.github.io/HDTDP/`).
   - Hệ thống đóng gói & phát hành tự động cho Admin:
     + `DONG_GOI_TAT_CA.bat`: Biên dịch siêu tốc qua `PM_HoaDon.spec` (loại bỏ >30 thư viện AI/PyQt thừa,
       giảm dung lượng nén còn ~36.8 MB), chỉ đóng gói gọn `PM_HoaDon.exe` và thư mục `_internal` bằng
       `tar.exe` đa luồng của Windows, đồng bộ 5 file chuẩn sang `CAP_NHAT_GITHUB\`.
     + `DAY_LEN_GITHUB.bat` + `PC/upload_release.py`: Tự động `git commit` & `git push` 5 file Web/Config
       lên nhánh `main` và gọi GitHub REST API tạo/cập nhật Release Tag, đẩy `PM_HoaDon.zip` lên GitHub Releases.
